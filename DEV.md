See the [`iris` branch](https://github.com/Luracasmus/grindstone/tree/iris) for the Iris shader pack edition, which uses compute shaders. Beware that it only implements SMAA 1x and may be out of date compared to the vanilla edition. Also see the implementation in [RenderPearl](https://github.com/Luracasmus/renderpearl).

The [`aperture` branch](https://github.com/Luracasmus/grindstone/tree/aperture) contains an incomplete Aperture port.
